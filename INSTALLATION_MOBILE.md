# 📱 Installation sur Mobile - Guide Complet

L'application **Portail SRP** est une **Progressive Web App (PWA)** qui s'installe comme une vraie app sur votre téléphone !

---

## ✨ Avantages de l'installation

- 🚀 **Accès rapide** : Icône sur l'écran d'accueil
- 📴 **Fonctionne hors ligne** : Consultez vos données sans internet
- 🔔 **Notifications push** : Recevez les alertes importantes
- 💾 **Économise la batterie** : Plus efficace qu'un onglet navigateur
- 🎯 **Mode plein écran** : Expérience native sans barre d'adresse

---

## 📱 Installation sur Android (Chrome/Samsung Internet)

### Méthode automatique (recommandée)

1. **Ouvrir l'app** dans Chrome : `https://votre-domaine.com`
2. **Attendre la bannière** d'installation (apparaît automatiquement)
3. **Cliquer sur "Installer"**
4. ✅ **L'icône apparaît** sur l'écran d'accueil

### Méthode manuelle

1. **Ouvrir l'app** dans Chrome
2. **Menu** (⋮) en haut à droite
3. **"Ajouter à l'écran d'accueil"** ou **"Installer l'application"**
4. **Confirmer** le nom et l'icône
5. ✅ **C'est installé !**

## 🖥️ Installation sur Desktop (Windows/Mac/Linux)

### Chrome / Edge

1. **Ouvrir l'app** : `https://votre-domaine.com`
2. **Icône d'installation** dans la barre d'adresse : **⊕** ou **💾**

## 🔄 Mise à jour de l'app

### Automatique

Les mises à jour se téléchargent **automatiquement** en arrière-plan. Quand une mise à jour est prête :

1. **Bannière de notification** apparaît
2. **"Nouvelle version disponible"**
3. **Cliquer "Mettre à jour"**
4. ✅ **L'app redémarre** avec la nouvelle version

### Manuelle

Si tu veux forcer une mise à jour :

1. **Fermer complètement l'app** (swipe up dans le gestionnaire)
2. **Rouvrir l'app**
3. **Attendre 5-10 secondes** (vérification en arrière-plan)
4. Si une mise à jour existe, la bannière apparaît

## 🐛 Problèmes courants

### "Impossible d'installer" (Android)

**Causes :**
- Espace de stockage insuffisant
- Version Android trop ancienne (< 5.0)
- Chrome pas à jour

**Solutions :**
1. Mettre à jour Chrome
2. Libérer de l'espace
3. Redémarrer le téléphone

---

### "Bouton d'installation invisible" (Android)

**Causes :**
- Déjà installée
- Bannière fermée précédemment

**Solutions :**
1. Désinstaller l'app si elle existe
2. Vider le cache de Chrome
3. Utiliser la méthode manuelle (Menu > Installer)

---

### "Pas d'option 'Sur l'écran d'accueil'" (iOS)

**Causes :**
- Pas dans Safari (Chrome iOS ne supporte pas)
- Mode navigation privée
- Restrictions iOS

**Solutions :**
1. Ouvrir dans Safari (pas Chrome)
2. Quitter le mode navigation privée
3. Vérifier Réglages > Temps d'écran > Restrictions

---

### "L'app ne fonctionne pas hors ligne"

**Causes :**
- Première connexion pas terminée
- Cache pas synchronisé
- Données pas sauvegardées

**Solutions :**
1. Se connecter une fois avec internet
2. Naviguer dans toutes les sections principales
3. Attendre 30 secondes (sync automatique)
4. Vérifier dans DevTools > Application > Service Workers

## 🔐 Sécurité et vie privée

### Données stockées localement

- ✅ **Session utilisateur** (hashée, sécurisée)
- ✅ **Cache des interventions** (chiffré)
- ✅ **Notes de frais** (stockage sécurisé IndexedDB)
- ❌ **Mots de passe en clair** (jamais stockés)

### HTTPS requis

L'app nécessite **HTTPS** pour :
- Service Worker
- Notifications push
- Mode hors ligne
- Stockage sécurisé

### Effacer les données

Pour effacer toutes les données locales :

**Console navigateur (F12) :**
```javascript
// Effacer tout
indexedDB.deleteDatabase('srp-offline-db');
localStorage.clear();
sessionStorage.clear();
location.reload();
```

## 📞 Support

### Vérifier l'installation

```javascript
// Console (F12)
if (window.matchMedia('(display-mode: standalone)').matches) {
  console.log('✅ App installée et lancée en mode standalone');
} else {
  console.log('❌ App ouverte dans le navigateur');
}
```

### Vérifier le Service Worker

```javascript
// Console (F12)
navigator.serviceWorker.getRegistration().then(reg => {
  if (reg) {
    console.log('✅ Service Worker enregistré');
    console.log('Scope:', reg.scope);
    console.log('État:', reg.active?.state);
  } else {
    console.log('❌ Pas de Service Worker');
  }
});
```
